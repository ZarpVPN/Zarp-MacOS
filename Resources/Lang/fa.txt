# Account setup and protected API recovery
err.accountUncertain = ممکن است Cloudflare حساب را ساخته باشد، اما پاسخ از دست رفته است. ثبت خودکار برای جلوگیری از حساب تکراری متوقف شد. فایل‌های فعلی حساب را نگه دارید.
err.accountUnavailable = خواندن امن داده‌های فعلی حساب انجام نشد. دسترسی پوشهٔ داده را بررسی کنید. Zarp حساب را جایگزین نمی‌کند.
err.accountRateLimited = Cloudflare درخواست‌های ثبت را محدود کرده است. پیش از تلاش دوباره صبر کنید. ثبت ناتمام حفظ شده است.
err.accountCertificate = گواهی API کلادفلر تأیید نشد. ثبت متوقف شد.
err.accountNetwork = با راهبردهای TLS موجود، دسترسی به API حساب Cloudflare انجام نشد. داده‌های ثبت ناتمام حفظ شده‌اند.
err.accountRejected = API حساب Cloudflare درخواست را رد کرد یا پاسخ نامعتبر داد. حساب را بررسی و وضعیت آن را تازه‌سازی کنید.
err.licenseUncertain = ممکن است درخواست مجوز به Cloudflare رسیده باشد. پیش از ارسال دوبارهٔ کلید، حساب را تازه‌سازی کنید.
