# Zarp for macOS 1.0.0

Zarp combines WARP or a configured server tunnel with a portable outer zapret
strategy, confirms real traffic and remembers compatible selections.

## Changes

- Automatic background-service preparation at startup, after updates and before
  connection or account actions, with authorization handled by macOS.
- Twenty-four WARP strategies, alternate TLS names, retry-handshake coverage,
  country filters, saved confirmations and fallback. Plain WARP connections
  are disabled.
- QUIC TCP packet-size correction for the locally reproduced HTTPS stall,
  plus bounded transport diagnostics without payloads, keys or reset tokens.
- Manual server links, HTTPS subscriptions, source/server selection and saved
  server + strategy pairs. Bundled sing-box and Xray keep their pinned versions.
- XHTTP import and all four modes, HTTP/3, bounded extra options and separate
  download legs through the outer strategy relay.
- WARP+ account management, protected account setup, application routing
  controls and nine interface languages, including Persian with RTL support.

## Verification and remaining limits

Private HTTPS/UDP transport tests cover the bundled backends and native WARP
transports. The user's 0.4.8 logs also confirm real traffic through both
alternate-name HTTP2 profiles. The 1.0.0 build passes Go formatting, vet and
race checks, all 351 Swift tests, third-party notices, and signed bundle and
disk-image checks. Details are recorded in the
[implementation progress](https://github.com/ZarpVPN/Zarp-MacOS/blob/v1.0.0/docs/IMPLEMENTATION_PROGRESS.md).

Recovery from the recorded mobile QUIC stateless resets remains unverified.
The QUIC packet-size correction fixes a separate reproduced defect. Actual
product TUN, positive signed-release backend acceptance, real ECH and
Reality-XHTTP combinations, and complete XHTTP extra-field compatibility
also remain unverified. WireGuard and raw-socket techniques are unavailable.

## Installation

Requires Apple Silicon and macOS 14 or later. Download
`Zarp-1.0.0-arm64.dmg`, drag `Zarp.app` to Applications and open it there.
The Apple Development signed release is not notarized. Allow the first launch
in System Settings > Privacy & Security > Open Anyway, as described in the
[README](https://github.com/ZarpVPN/Zarp-MacOS/blob/v1.0.0/README.md#why-wont-zarp-open). Zarp prepares its service
automatically; approve macOS authorization or background activity if requested.
